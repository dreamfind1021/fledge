# fledge-tasks — 專案待辦

## 定位

管兩種待辦：**使用者腦中的念頭**，以及**工作中撞到、之後要處理的事**。

一個功能開工後拆成的細票（`.scratch/<功能>/issues/`）不歸這裡管，那是另一套成熟系統，不要動它。

**判斷「這件事值不值得記」的人是使用者，不是你。** 你只負責「記成什麼樣」。

---

## 與「記憶」的分界

「記一下」這句話同時是 Claude Code 內建記憶系統的觸發句，而那套指示住在 system prompt、
層級比 skill 高。**光憑「記一下」三個字進不來這支 skill**（2026-08-31 打包驗收實測）。

分界很清楚：

| 使用者想存的東西 | 歸誰 |
|---|---|
| 這個專案之後要做的事 | **本 skill** → `.fledge/tasks/` |
| 使用者的偏好、工作方式的指正、跨專案的事實、外部連結 | 記憶系統 → `memory/` |

使用者只說「記一下」而你判斷不出是哪一種時，**問一句**，不要猜。

## 檔案在哪、長什麼樣

```
<當前專案根目錄>/.fledge/tasks/07-匯出檔名要能自訂.md
```

一件事一個檔案。沒有資料庫、沒有索引檔、沒有 CLI 指令——**你直接讀寫 markdown 檔案**。

```markdown
---
status: todo
source: ai
created: 2026-08-29
---

# 匯出的檔名要能自訂

recipe-box 的匯出目前寫死檔名，多份會互相蓋掉。
```

| 位置 | 欄位 | 值 |
|---|---|---|
| 檔名前綴 | 編號 | `01` 起的流水號，**唯一真相源**，不要寫進 frontmatter |
| frontmatter | `status` | `todo` / `doing` / `done` |
| frontmatter | `source` | 你開的一律 `ai`（`me` 是使用者從面板建的） |
| frontmatter | `created` | `YYYY-MM-DD`，開票當天 |
| 第一個 `# ` 行 | 標題 | 自由文字，一行 |
| 其後 | 內文 | 自由文字，可省略 |

**欄位名與值一律英文**，這是與 Fledge 面板之間的格式合約。標題與內文是使用者的自由文字，語言不限。

---

## 編號怎麼取

1. 列出 `.fledge/tasks/` 底下所有 `NN-*.md`，取**最大的 `NN` 加一**
2. 如果那個檔名已經存在，**再加一，重試**
3. 資料夾是空的或不存在，從 `01` 開始（不存在就建，含 `.fledge/` 那層）

**這只是避開已經存在的檔名，不保證編號不會撞。** 面板那邊也在配號，兩邊同時建票時可能拿到同一個編號。真的撞到時，Fledge 會把兩張票都顯示出來、都標成異常，由使用者手動改檔名——**不要自己去改別人的票檔來「修正」編號**。

---

## 檔名的短名

`NN-<短名>.md` 的短名純粹給人在 Finder 裡辨識，Fledge 只靠 `NN` 認人。從標題截一段看得懂的即可，中文可用。**不要放 `/`、`.`、空白**。

---

## 開票前的煞車

1. **使用者沒開口就不要開票。** 你自己覺得「這個以後要處理」不算理由——說出來讓使用者決定。
2. **五分鐘做得完的別開票**，直接做掉。
3. **先看現有清單。** 已經有意思相近的票，就把新資訊補進那一張的內文，不要開第二張。
4. **一張票只講一件事。** 需要分兩件做，就開兩張。
5. **標題要能直接動手。** 「處理匯出問題」不合格；「匯出檔名改成可自訂，避免多份互蓋」合格。

---

## 讀票

使用者問「待辦有哪些」「還有什麼沒做」時：列出 `.fledge/tasks/` 底下的 `*.md`，讀每個檔的 `status` 與標題，把 `todo` 與 `doing` 的報給使用者，`done` 的除非被問到否則不列。

**列清單只需要 frontmatter 與第一個 `# ` 行，不要把每個檔案的全文讀出來**——票一多會把整個 context 灌爆。要看內文是使用者指名某一條的時候的事。

使用者說「看第 7 條」時：找檔名前綴是 `07` 的那個檔，讀全文。

**讀票就只是讀票。** 使用者問清單的時候不要順手開新票、不要順手改狀態。

---

## 改狀態與刪除

使用者明講「第 7 條做完了」之類的話時，改那個檔的 `status` 那一行，**其餘內容一個字都不要動**。

**不要刪票檔。** 做完就是 `status: done`，檔案留在原地——寫過的分析做完就消失，那正是這套東西要避免的事。使用者明講要刪才刪。
